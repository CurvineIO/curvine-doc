# Curvine Documentation Site

## Project Overview

This repository builds **curvineio.github.io** with **Fumadocs** (Next.js App Router + static export). The legacy Docusaurus setup has been fully replaced — do not edit `docusaurus.config.ts`, `sidebars.ts`, root `src/` Docusaurus pages, or the root `package.json` (these no longer exist / are not used).

### Framework and references

| Concern | Location |
| --- | --- |
| Fumadocs site (the real site) | `site/` — Next.js App Router, static export (`output: 'export'`) |
| Docs & blog **content sources** (edit here) | repo root: `docs/`, `blog/`, `i18n/zh-cn/...`, `static/` |
| Generated Fumadocs content (**do not edit**) | `site/content/`, `site/public/` (gitignored) |
| Content conversion scripts | `site/scripts/sync-content.mjs` (docs), `site/scripts/sync-blog.mjs` (blog) |
| Fumadocs config (collections, MDX plugins) | `site/source.config.ts` |
| Page components | `site/src/app/` (routes), `site/src/components/` (UI) |
| Locale / search / loaders | `site/src/lib/` (`source.ts`, `i18n.ts`, `blog.ts`) |
| Theme colors (Curvine green) | `site/src/app/global.css` (`--color-fd-primary`) |
| Deploy pipeline | `.github/workflows/deploy-fumadocs.yml` (builds `site/`, publishes `site/out` to GitHub Pages on merge to main) |

### How content flows

```
docs/1-Overview/01-instroduction.md   ─┐
i18n/zh-cn/.../current/...            ─┤  npm run sync (in site/)
blog/2025-07-15-what-is-curvine/index.md  ├→  site/content/*.mdx  →  Fumadocs pages
i18n/zh-cn/.../blog/...               ─┘
static/ (img/, install.sh, helm-charts/) →  site/public/
```

- **Always edit the sources** (`docs/`, `blog/`, `i18n/`, `static/`), then run `npm run sync` inside `site/` to regenerate `content/` and `public/`.
- `site/content/` and `site/public/` are **generated and gitignored** — never hand-edit them.
- The conversion preserves old Docusaurus URLs (`/docs/Deploy/quick-start`, `/blog/2025/07/15/...`), sidebar order, and zh-cn locale routing (`/zh-cn/...`).

### Development commands

```bash
cd site
npm install        # first time
npm run sync       # regenerate content/ + public/ from root sources
npm run typecheck  # tsc --noEmit (run sync first)
npm run dev        # http://localhost:3000
npm run build      # static export to site/out
npm run preview    # serve site/out
```

- Deploys happen automatically on merge to main via `deploy-fumadocs.yml`. PRs only build + typecheck (no publish).
